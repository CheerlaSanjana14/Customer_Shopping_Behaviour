# 📊 Customer Purchase Behaviour Analysis Dashboard – Excel

## 📌 Project Overview
This project focuses on analysing customer purchasing behaviour using Microsoft Excel. An interactive dashboard was developed to transform raw shopping data into meaningful insights through data analysis and visualization.

The dashboard helps understand customer preferences, purchasing patterns, product performance, and seasonal trends.

## 🎯 Project Objectives
- Analyse customer purchasing behaviour.
- Identify popular product categories.
- Understand purchasing patterns across different age groups and genders.
- Analyse seasonal shopping trends.
- Explore customer payment and shipping preferences.
- Understand the impact of discounts and promotional offers.

## 🛠️ Tools & Technologies
- **Microsoft Excel**
- Pivot Tables
- Pivot Charts
- Slicers
- Excel Formulas
- Data Visualization

## 📈 Dashboard Features

The dashboard includes the following visualizations:

1. Revenue by Product Category
2. Purchase Amount by Age Group
3. Purchase Behaviour by Gender
4. Seasonal Shopping Trends
5. Payment Method Analysis
6. Shipping Type Preferences
7. Customer Purchase Frequency
8. Customer Ratings Analysis
9. Discount and Promo Code Analysis
10. Customer Loyalty Analysis

## 🎛️ Interactive Filters
The dashboard includes slicers to filter data based on:
- Gender
- Product Category

These filters help explore customer purchasing patterns from different perspectives.

## 💡 Key Learnings
Through this project, I gained practical experience in:
- Working with and analysing real-world datasets.
- Creating Pivot Tables and Pivot Charts.
- Using slicers to filter dashboard data.
- Applying Excel formulas for analysis.
